## Verificación de Comandos para el Docente

Para comprobar cualquier resultado de esta matriz en vivo desde la consola de Windows:

```powershell
# 1. Comprobar integridad criptográfica del dataset público OWID
python scripts/check_owid_source.py

# 2. Comprobar ejecución de la suite de 83 pruebas automatizadas
.\.venv\Scripts\python.exe -m pytest tests/ -q

# 3. Comprobar generación de los 4 informes en PDF y Excel
.\.venv\Scripts\python.exe scripts/test_reports_live.py

# 4. Comprobar compilación estricta de TypeScript y bundle de React
npm run build
```
